# Reed Discover 0.1 — Personal Reading Feed

Персональная лента для спокойного выбора статей. Откройте сайт, добавьте
интересные материалы кнопкой **«Почитать позже»**, а затем читайте, отмечайте
прочитанными или скачивайте свою подборку как EPUB.

Первая версия использует «Мир фантастики» и восемь тематических RSS-источников и продолжает выпускать
прежний полнотекстовый RSS для KOReader. Никакого платного сервера: каталог
обновляет GitHub Actions, сайт раздаёт GitHub Pages, а подборка хранится только в
браузере пользователя.

## Что уже работает

- карточки с заголовком, источником, аннотацией и оценкой времени чтения;
- добавление произвольной ссылки в ту же личную подборку;
- фильтр по теме, «Моя подборка», удаление и статус «Прочитано»;
- локальная подборка без регистрации (`localStorage`);
- EPUB 3 из выбранных материалов, собираемый прямо в браузере;
- исходный `feed.xml` и полнотекстовые страницы для RSS-клиентов и KOReader;
- автоматическое обновление и публикация каждые три часа.

Темы каталога: доступный научпоп, настольные игры, программирование и технологии,
геймдизайн и компьютерные игры. Текущий состав источников хранится в
`config/sources.json`; сбой отдельной внешней ленты не останавливает обновление
MirF и публикацию сайта.

> Подборка привязана к браузеру и устройству. Очистка данных сайта удалит её.
> Экспорт EPUB — способ забрать выбранные материалы с собой.

Для материалов из общей ленты EPUB включает полный подготовленный текст. Для
добавленной вручную внешней ссылки статическая версия сохраняет название и адрес:
автоматическое извлечение произвольных сайтов требует опционального Reed Me Later
Worker из соседнего проекта.

## Локальный запуск

В сборке используется Python 3.12.

```bash
python -m pip install -r requirements.txt
python generate_feed.py
python validate_feed.py
python -m unittest discover -s tests -v
python -m http.server 8000 -d public
```

После этого приложение доступно на `http://localhost:8000`, а RSS — на
`http://localhost:8000/feed.xml`. Открывать `index.html` напрямую не следует:
браузер блокирует загрузку JSON с `file://`.

Параметры генератора: `--output` задаёт RSS-файл (по умолчанию
`public/feed.xml`), `--limit` — число материалов (по умолчанию 30).

## Публикация

Workflow **Update full-text RSS feed** запускается по расписанию и вручную. Он:

1. загружает официальный Atom MirF и страницы материалов;
2. обновляет `feed.xml`, `items/*.html` и `data/articles.json`;
3. валидирует RSS, каталог и тесты совместимости;
4. публикует весь `public/` в GitHub Pages.

Существующую подписку KOReader менять не нужно: `feed.xml` остаётся в корне Pages
и сохраняет прежнюю RSS 2.0-схему, полные тексты и стабильные `guid`.

## Структура

```text
generate_feed.py           сборка MirF, RSS, страниц и каталога
config/sources.json        реестр текущих и будущих источников
public/index.html          Reed Discover
public/assets/             интерфейс и локальный EPUB-экспорт
public/data/articles.json  каталог рекомендаций
public/feed.xml            совместимый полнотекстовый RSS
public/items/              страницы статей
docs/architecture.md       решения, контракты и план новых RSS-источников
tests/                     тесты каталога и обратной совместимости
```

Подробности: [архитектура Reed Discover](docs/architecture.md).

## Права на материалы

Тексты и изображения принадлежат их правообладателям. Проект преобразует
публично доступные страницы для личного чтения и не копирует изображения.
